# FLOWFRAME — Frontend

> Logic First, Pixel Second.

FLOWFRAME è uno spazio di lavoro digitale per designer e sviluppatori che impone la struttura prima dell'estetica. Questa repository contiene l'applicazione client, un ambiente di wireframing logico a blocchi con un assistente AI integrato.

## Funzionalità Chiave

- **Workspace a Blocchi**: Progettazione strutturale tramite componenti gerarchici (Stacks, Columns, DataLists, Forms) manipolabili tramite ordinamento dinamico.
- **Interfaccia AI Integrata**: Chat di assistenza contestuale per la generazione di layout, l'ottimizzazione dei flussi e la validazione logica delle interfacce.
- **Stato Centralizzato**: Gestione delle sessioni utente, dei progetti attivi e dei blocchi dell'interfaccia tramite Redux Toolkit.
- **Sistema di Accesso Protetto**: Flussi di autenticazione pronti per la produzione con verifica dell'identità via email e protezione delle rotte private.

## Stack Tecnologico

- React 18
- TypeScript
- Vite
- Redux Toolkit
- Tailwind CSS
- React Router v6

## Configurazione Locale

Crea un file `.env` nella radice del progetto:

```env
VITE_GEMINI_API_KEY=la_tua_api_key_di_gemini
```
